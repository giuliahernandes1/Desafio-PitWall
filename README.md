# 🏁 Pit Wall — GP de São Paulo (Interlagos) 🏎️💨

Projeto desenvolvido para o **Desafio Pit Wall** da disciplina **LIMA (Linguagem de Marcação)**. O objetivo da atividade é recriar a página temática do Grande Prêmio de São Paulo de Fórmula 1, em Interlagos, utilizando apenas **HTML5** e **CSS3**, aplicando os conceitos aprendidos no projeto *Sistema Musical* e garantindo responsividade para desktop e dispositivos móveis.

---

## 🛠️ Tecnologias e Conceitos Aplicados

* **HTML5 Semântico:** Estruturação organizada com `header`, `main`, `section`, `footer` e tabelas completas (`thead` e `tbody`) para a classificação.
* **Variáveis CSS (`:root`):** Padronização e gerenciamento das cores oficiais das equipes.
* **Flexbox:** Alinhamento e distribuição de elementos no topo (cabeçalho), na seção *Hero* e nos filtros.
* **CSS Grid:** Layout responsivo com `auto-fit` para os cards dos pilotos e `form-grid` para o formulário de compra de ingressos.
* **Responsividade (`@media`):** Adaptação do layout para telas menores (smartphones e tablets).
* **Estilização Avançada:** Tipografia personalizada via **Google Fonts**, imagens de fundo e efeito visual simulando a zebra da pista.
